# Project Based Internship

##  Cyber Security Internship – Kali Linux Domain

**Duration:** 6 Weeks (03rd June 2024 – 15th July 2024)

**Platform:** IBM SkillsBuild

**Organized by:** Edunet Foundation in collaboration with Andhra Pradesh State Skill Development Corporation (APSSDC)

###  Overview

This 6-week intensive virtual internship focused on **Cybersecurity principles and practices**, with a strong hands-on emphasis using the **Kali Linux platform**. Designed to simulate real-world environments, the internship empowered participants with the knowledge and skills required to navigate today's digital threat landscape.

The internship was powered by **IBM’s SkillsBuild platform**, ensuring access to high-quality, industry-relevant learning content, labs, and assessments. The sessions covered foundational and intermediate concepts of cybersecurity, ethical hacking, and penetration testing.

###  Internship Highlights

* **Hands-on Training with Kali Linux:**
  Practiced offensive security techniques using pre-installed tools like Nmap, Wireshark, Burp Suite, Metasploit, and more.

* **Foundational Cybersecurity Concepts:**
  Gained an in-depth understanding of network security, threat modeling, malware types, risk management, and encryption protocols.

* **Practical Exposure to Penetration Testing:**
  Performed vulnerability scanning, footprinting, reconnaissance, and basic exploitation tasks in simulated lab environments.

* **Use of IBM SkillsBuild Platform:**
  Completed curated learning paths with modules in network security, ethical hacking basics, system hardening, and cybersecurity compliance.

###  Skills Acquired

* Kali Linux OS & Tools
* Network and Web Application Scanning
* Vulnerability Assessment
* Threat Identification and Mitigation
* Ethical Hacking Methodologies
* Digital Forensics Basics
* Reporting and Documentation

### Outcomes

* Developed a hacker’s mindset to think like an attacker and defend like a pro.
* Improved technical problem-solving by simulating real attack scenarios.
* Gained industry exposure through a government-recognized internship program.
